잠금 화면 배경화면으로 설정하는 방법

iPhone에서

  1. 이 배경화면 저장을 탭한 다음 이미지 저장을 탭하세요. 이미지는 사진 앱에 저장돼요.
  2. 설정 → 배경화면을 열고 새로운 배경화면 추가를 탭하세요.
  3. 사진을 탭하고 이미지를 고르세요.
  4. 추가를 탭한 다음 배경화면 쌍으로 설정을 탭하세요. 앱 뒤를 더 차분하게 두고 싶다면 홈 화면 사용자화를 탭하세요.

Android에서

  1. 이 배경화면 저장을 탭하세요. 이미지는 다운로드 폴더에 저장돼요.
  2. Google 포토나 갤러리 앱에서 이미지를 여세요.
  3. 메뉴(점 세 개)를 탭하고 다른 앱에서 사용 또는 배경화면으로 설정을 고르세요.
  4. 잠금 화면을 고르세요.

시계가 글자를 가리지 않게 하는 요령과 사진 셔플로 여러 장을 번갈아 보는 방법은 전체 가이드에서 자세히 알려 드려요: iPhone에서 글귀 배경화면을 만드는 방법.

자주 묻는 질문

배경화면은 무료인가요?

네. 원하는 만큼 저장하세요. 배경화면마다 아래쪽 가장자리 근처에 작은 mydailies.app 표시가 들어가요.

크기는 어떻게 되나요?

1080×2340픽셀로, 요즘 휴대폰 화면처럼 세로로 긴 모양이에요. 휴대폰이 화면에 맞게 이미지를 조정하고, 글자는 시계에 가리지 않아요.

시계가 글귀를 가리지 않나요?

가리지 않아요. 글자는 이미지의 아래쪽 절반, 시계와 잠금 화면 위젯 줄보다 아래에 들어가요. 시계를 아주 크게 늘려 두었다면 잠금 화면을 사용자화할 때 작게 줄이세요.

글귀는 누가 썼나요?

대부분 Dailies를 위해 쓴 글귀예요. 나머지는 저작권이 만료된 작가의 글이고, 글귀 아래에 이름이 있어요.

다른 사람에게 보낼 수 있나요?

네. 저장해서 이미지를 보내거나, 격려의 말 페이지에서 글귀를 봉투에 담아 보내세요.

이런 글귀가 필요한 사람이 있나요? 봉투에 담아 보내 보세요.
