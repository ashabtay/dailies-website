Android でウィジェットを追加する方法

ほとんどの Android スマートフォンでは、ホーム画面を長押しし、「ウィジェット」を開き、ウィジェットをドラッグして置く、という同じ三つの動作です。呼び方はメーカーによって少しずつ違うので、このページではその違いを整理し、探しているウィジェットが見つからないときや止まったときの対処もまとめます。

ウィジェットを追加する

iPhone をお使いなら、ホーム画面にウィジェットを追加する方法をご覧ください。

Google の Android ヘルプに載っている手順で、ほとんどの Android スマートフォンで使えます。例として Dailies を挙げていますが、ウィジェットのあるアプリならどれも同じです。

  1. ホーム画面の何もない場所を長押しします。アイコンもウィジェットもない場所です。
  2. 「ウィジェット」をタップします。
  3. 目的のウィジェットがあるアプリを探し（Dailies など）、タップしてウィジェットの一覧を開きます。
  4. ウィジェットを長押しします。ホーム画面の画像が表示されます。
  5. 置きたい場所までスライドして、指を離します。

Google によると、これらの手順の一部は Android 14 以降でのみ使えます。古い機種ではメニューの見た目が違うことがありますが、長押しして「ウィジェット」、ドラッグという流れは同じです。

多くの機種にある近道が二つあります。ウィジェットの一覧の上には検索欄があることが多く、長い一覧をスクロールするより早く見つかります。また、アプリのアイコンを長押しすると小さなメニューが開き、多くの機種ではそこからそのアプリのウィジェットに直接進めます。

Samsung Galaxy の場合

Galaxy は Samsung 独自の Android である One UI を使っていて、Samsung のヘルプでは、ウィジェットをドラッグする代わりに、選んでボタンをタップします。

  1. ホーム画面の何もない場所を長押しします。
  2. 画面下部の「ウィジェット」をタップします。おすすめのウィジェットが先に表示されるので、ほかのものは下にスクロールして探します。
  3. アプリをタップし、目的のウィジェットをタップします。スタイルやサイズが複数あるウィジェットは、ここで選びます。
  4. 「追加」をタップします。ウィジェットがホーム画面に置かれます。

置いたウィジェットを長押しすると、Samsung のメニューが開きます。ウィジェットが対応していれば背景色や透明度などを変えられ、「削除」をタップするとホーム画面から取り除けます。Samsung では、ウィジェットを同じ場所に重ねてスワイプで切り替えることもできます。

Google Pixel の場合

Pixel は Google 自身のスマートフォンなので、このページの最初の手順がそのまま Pixel の手順です。何もない場所を長押しし、「ウィジェット」をタップし、アプリをタップしてから、ウィジェットを長押ししてドラッグします。

  • 一覧はアプリごとにまとまっています。各アプリは一度だけ表示されるので、タップしてウィジェットを開きます。上の検索欄にアプリ名を入力することもできます。
  • ドラッグしなくてよいバージョンもあります。一覧でウィジェットをタップすると追加用のボタンが表示され、それをタップすると Pixel が空いている場所に置きます。

サイズ変更、移動、削除

サイズを変える

  • ウィジェットを長押しして、指を離します。
  • サイズを変えられるウィジェットなら、点の付いた枠が表示されます。
  • 点をドラッグして、大きくしたり小さくしたりします。
  • 終わったら、ウィジェット以外の場所をタップします。

Samsung でも枠の使い方は同じで、点を長押ししてドラッグします。変えられるのはアプリが用意したサイズだけなので、画面の端に届く前に大きくならなくなることもあります。

移動する

ウィジェットを長押ししてドラッグします。ホーム画面の画像が表示されるので、新しい場所までスライドし（別のページに移すときは画面の端まで）、指を離します。

削除する

ウィジェットを長押しして、上の「削除」までドラッグします。Samsung では、長押しして「削除」をタップします。取り除かれるのはホーム画面のウィジェットだけで、アプリとその中身はそのまま残ります。同じ場所に「アンインストール」が表示される機種もあり、こちらはアプリそのものを消すので、どこで指を離すかよく確認してください。

アプリから追加する

Android 8 以降では、アプリがスマートフォンに、自分のウィジェットをホーム画面に置くよう頼めます。アプリの中で「ホーム画面に追加」のようなボタンをタップすると、Android がウィジェットのプレビューが入った専用の画面を表示します。

  • 確認するまで何も追加されません。その画面で確定するとウィジェットがホーム画面に置かれ、閉じれば何も変わりません。
  • 機種によっては自分で置くこともできます。プレビューを長押しして、好きな場所までドラッグします。
  • すべてのホーム画面が対応しているわけではありません。アプリは事前に確認できるため、機種によってはボタン自体が表示されません。このページの最初の手順なら、いつでも使えます。

うまくいかないとき

一覧にウィジェットがない

よくある原因の順に並べています。

  1. アプリを一度開きます。機種によっては、アプリを開いたあとでないとウィジェットが表示されません。試しても損はありません。
  2. スクロールせずに検索し、アプリ名のところを見ます。一覧はウィジェットの機能ではなく、アプリごとに並んでいます。
  3. そのアプリにウィジェットがあるか確認します。ウィジェットのないアプリもあります。
  4. アプリを入れ直します。アンインストールしてもう一度インストールし、一度開いてから、また探します。
  5. 仕事用プロファイルがないか確認します。仕事用プロファイルがある端末では、仕事用のアプリと個人用のアプリが分かれていて、ウィジェットの一覧でも別のタブに表示されることがよくあります。片方にしか入っていないアプリのウィジェットは、そちらにしか出てきません。
  6. Samsung では、レイアウトがロックされていないか確認します。何も追加も削除もできない、または項目がグレー表示になっている場合は、ホーム画面のレイアウトをロックする設定がオンになっているかもしれません。ホーム画面の設定でオフにします。

ウィジェットが更新されない

ウィジェットをいつ描き直すかを決めるのはアプリではなく Android で、バッテリーを節約するために後回しにすることがあります。

  • 「バッテリー セーバー」をオフにします。Samsung では名前が違いますが、バッテリーの設定にある省電力のモードがこれにあたります。どちらも、ウィジェットを含め、アプリがバックグラウンドで行う処理を抑えます。
  • アプリのバッテリー設定を確認します。「設定」→「アプリ」でアプリを開き、バッテリーの項目を見ます。バックグラウンドでの動作が制限されていたら、許可します。
  • Samsung では、スリープ中のアプリを確認します。バッテリーの設定にあるバックグラウンドでの使用制限で、Samsung がスリープさせるアプリの一覧からアプリを外します。
  • アプリを一度開きます。開いたときにウィジェットを描き直すアプリはたくさんあります。
  • ウィジェットを削除して、追加し直します。

画面の見た目が違う

ホーム画面そのものもランチャーと呼ばれるアプリで、メーカーごとに独自のものが入っています。Google のスマートフォンには Pixel Launcher、Samsung には One UI Home があり、Motorola、OnePlus、Xiaomi などにもそれぞれのものがあります。どれも長押しと「ウィジェット」のメニューは共通ですが、周りの言葉は変わります。自分でランチャーを入れた場合、ウィジェットのメニューはそのランチャーが用意した場所にあり、たいていは同じ長押しから開けます。このページの表記がお使いの機種と合わないときは、「ウィジェット」という言葉を探してください。

Android の Dailies ウィジェット

Dailies は、前向きになれる短い名言を届けるアプリです。Android 10 以降のスマートフォンでは、ホーム画面に言葉を表示します。知っておきたいことをまとめます。

  • ホーム画面だけです。Android には、ロック画面用のウィジェットはありません。それでも、通知として、またはギャラリーに保存した画像を壁紙に設定することで、ロック画面に言葉を表示できます。
  • 矢印とハートはその場で使えます。ホーム画面のまま、前後の言葉に移ったり、ハートを付けたりできます。
  • 言葉は毎時ちょうどに切り替わります。何も開かなくても、一時間ごとに新しい言葉になります。
  • アプリから置くこともできます。「カスタマイズ」→「ホーム画面のウィジェット」を開き、「ホーム画面に追加」をタップします。この機能がない機種もあるため、ボタンは使える端末にだけ表示されます。
  • 「バッテリー セーバー」で止まることがあります。言葉が変わらなくなったら、「バッテリー セーバー」をオフにして Dailies を一度開いてください。それでも直らなければ、ウィジェットを削除して追加し直します。

通知は「設定」→「アプリ」→「Dailies」→「通知」（場所は機種によって異なります）で、「毎日の言葉」がオンになっているか確認してください。そのほかのことはヘルプページにまとめています。

よくある質問

長押ししても「ウィジェット」が出てこないのはなぜですか？

アイコンかウィジェットを長押ししている可能性があります。その場合は、その項目のメニューが開きます。何もない場所を長押ししてください。機種によっては、ホーム画面を二本の指でつまむ操作でも同じメニューが開きます。

ウィジェットを削除すると、アプリもアンインストールされますか？

いいえ。「削除」はホーム画面からウィジェットを取り除くだけで、アプリとその中身はそのまま残ります。アプリを消すのは「アンインストール」です。

ウィジェットを大きく、または小さくするには？

ウィジェットを長押しして指を離し、枠の点をドラッグします。点が表示されない場合、そのウィジェットのサイズは一つだけです。

Android で Dailies のウィジェットをロック画面に置けますか？

いいえ。Android の Dailies には、ホーム画面用のウィジェットしかありません。それでも、通知として、またはギャラリーに保存した画像を壁紙に設定することで、ロック画面に言葉を表示できます。

Dailies のウィジェットが変わらなくなったのはなぜですか？

たいていは、スマートフォンがバッテリーを節約しているためです。「バッテリー セーバー」をオフにして、Dailies を一度開いてください。それでも直らなければ、ウィジェットを削除して追加し直します。
