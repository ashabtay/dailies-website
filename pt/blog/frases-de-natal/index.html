Como usar num cartão ou numa mensagem

  • Coloque a frase primeiro e uma linha sua depois. Uma boa frase abre o cartão. Uma frase sobre essa pessoa e sobre este ano é o que ela vai guardar.
  • Escolha a frase pela pessoa. Uma sobre dar para a pessoa mais generosa que você conhece, uma sobre o lar para a família, uma curta para a etiqueta do presente.
  • Mantenha o nome do autor. É o justo, e assim quem lê pode ir atrás de mais.
  • As curtas viajam melhor. Na tela do celular ou embaixo de uma foto, uma linha de dez palavras ou menos se lê num relance.

Perguntas

Que frase colocar num cartão de Natal?

A de Joseph Joubert, “A amabilidade e a boa acolhida são um convite que circula o ano inteiro”, serve para quase todo mundo. Para a família, a de Christian Morgenstern, “O lar não é onde moramos, mas onde nos compreendem”, é uma escolha bonita.

Qual é uma frase de Natal curta para mandar numa mensagem?

“Você só pode ter paz se a der”, de Marie von Ebner-Eschenbach, e “Ter o amor não é perder a luz”, de Victor Hugo, cabem numa mensagem ou numa etiqueta de presente.

O que escrever num cartão de Natal além de uma frase?

Uma linha que só sirva para essa pessoa: algo que vocês viveram este ano, algo que você agradece ou algo que quer fazer com ela no ano que vem. Uma frase concreta vale mais que uma frase espirituosa.

Tem algum versículo da Bíblia sobre luz para o Natal?

Uma das leituras tradicionais do Natal é Isaías 9:2: “O povo que andava em trevas, viu uma grande luz”.
