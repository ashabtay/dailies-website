iPhone 聖誕節鎖定畫面點子

十二月是大家唯一會為了季節特地更換鎖定畫面的月份。以下是五種值得照著做的聖誕節設定，每一種都附上步驟，還有如何留著平常的鎖定畫面，讓一月只需要滑一下就能換回來。

Amit Shabtay（Dailies 開發者） 撰寫於 2026年11月12日，適用於 iOS 27

本頁內容

首先，留著平常的鎖定畫面

你不必放棄現在的鎖定畫面。iOS 可以保留好幾個，一秒就能切換，所以把聖誕節的版本做成一個新的鎖定畫面：

  1. 解鎖 iPhone，然後按住鎖定畫面。停留在鎖定畫面，不要向上滑動。必須先用 Face ID 或密碼解鎖，否則按住也不會有任何反應。
  2. 點一下「+」按鈕。這會開始建立一個新的鎖定畫面。現在這個會留在列表中。
  3. 做出你的聖誕節鎖定畫面。挑一張背景圖片並加入小工具，參考下面其中一種設定。
  4. 點一下「加入」。然後選擇主畫面要用同一張圖片，還是另外一張。

到了一月，按住鎖定畫面，滑回平常那一個再點一下就好。如何更換或刪除鎖定畫面會說明怎麼移除聖誕節的那一個。

五種聖誕節設定

1. 雪景照片，時鐘下方放一句話

一張上方有天空的冬日照片，讓時間清楚好讀：下雪的街道、結了霜的窗戶、黑暗中點亮的聖誕樹。如果照片有明確的主體，iOS 可以讓它站到時鐘前面；編輯畫面中的分層按鈕可以開啟或關閉這個效果。

然後點一下時間下方的空間，加入句子小工具。Dailies 會在那裡放一句來自你所追蹤主題的短句，大約每小時換一次，所以每次拿起 iPhone 都有新的東西可讀。步驟請見如何在 iPhone 鎖定畫面上放句子。

2. 往年的聖誕節，隨機顯示

去年的聖誕節照片，一次一張。在圖庫中選擇「照片隨機顯示」，自己挑照片，而不是讓 iOS 幫你選。然後設定更換的頻率：點一下時、喚醒時、每小時或每天。選喚醒時，每次拿起 iPhone 都會看到不同的聖誕節。

3. 屬於這個季節的經文

如果你的聖誕節不只是購物，就讓一節聖經經文整個十二月都待在時鐘下方。在 Dailies 中，到「個人化」的「主題」追蹤「今日經文」，再把 Dailies 小工具加到時間下方。如何在 iPhone 鎖定畫面上放聖經經文會一步步說明。

4. 紅與綠，簡單就好

完全不用照片。在圖庫中選擇「顏色」，挑一種深紅色或森林綠。點一下時間，把它設成柔和的米白色或白色；日期和小工具也會使用同樣的顏色，整個畫面就會很協調。在時間下方加入一個小工具，其餘留空。簡單的畫面，周圍留點空間最好看。

5. 在主畫面上飄落的雪

這一個屬於主畫面，搭配你的聖誕節鎖定畫面。Dailies 有一種叫做「雪花球」的效果，會讓雪在你的句子後面飄落，而且到 2027年1月1日之前，所有人都可以免費使用。

  1. 選擇「雪花球」。在 Dailies 中打開「風格」，在「效果」下方挑選「雪花球」。
  2. 搖一搖。App 打開時搖一搖 iPhone，雪就會旋轉飛舞，就像真的雪花球一樣。
  3. 加入小工具。按住主畫面上的空白處，直到圖像開始晃動，點一下「編輯」，再點一下「加入小工具」。搜尋 Dailies，挑選中型或大型，然後點一下「加入小工具」。主畫面小工具上也會有雪。

讓它自動開啟

鎖定畫面可以連結到專注模式，這樣只要那個專注模式開啟，聖誕節的鎖定畫面就會出現：例如在家時的「個人」專注模式，而「工作」專注模式則保留平常的樣子。如何把鎖定畫面連結到專注模式會告訴你怎麼做。

常見問題

可以有聖誕節鎖定畫面，又不失去平常那一個嗎？

可以。按住鎖定畫面，點一下「+」建立一個新的。兩個都會留在列表中，直到你刪除其中一個，而且隨時都能切換。

要怎麼把聖誕節圖片放到鎖定畫面上？

按住鎖定畫面，點一下「+」，選擇「照片」並挑出那張圖片。用兩指捏合和拖動來調整位置，然後點一下「加入」。

Dailies 的「雪花球」是免費的嗎？

到 2027年1月1日之前，所有人都可以免費使用。之後它會再次成為 Premium 的一部分。

聖誕節過後要怎麼換回來？

按住鎖定畫面，滑到平常那一個再點一下。你可以把聖誕節的那一個留到明年，也可以刪除它。
